# NLP_uni
Университетские проекты по обработке текстов на естественном языке. Требования и суть задачи описаны в файле "Лабораторные работы".
Сделаны следующие темы:
1) Тема №1: Анализ отзывов клиентов онлайн-магазинов
2) Тема №3: Оптимизация поиска вакансий по резюме кандидатов
3) Тема №5: Обнаружение фишинга в сообщениях электронной почты
4) Тема №10: Мониторинг социального профиля бренда
5) Тема №12: Выявление поддельных отзывов
6) Тема №14: Фильтрация неподходящего контента
